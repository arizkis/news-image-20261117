A broadsheet-style front page that sums up 17 November 2026's world news in a single 1024x1024 image — three hero stories, fifteen numbered panels, a world map and an "also on Tuesday" list, 42 stories in all.

## Run it

```sh
node main.ts
```

Copies the bundled `entry.png` byte-for-byte to the output directory: `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`. Requires Node 22 and uses only the standard library; there is nothing to install.
